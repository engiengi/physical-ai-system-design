## 2. Franka 서랍 — 안정적인 열기와 닫힘 후 복구

대표 실행: `outputs/05_drawer/20260922_223639_56ea3f52/`

| 단계 | 실제 관찰 |
|---|---|
| 첫 열기 요청 | `open_drawer` 한 번으로 접근·양측 접촉 확인·당기기·놓기·후퇴·안정화 완료 |
| 첫 완료 보고 | 새 관찰을 바탕으로 모델이 `goal_complete` 보고 |
| 외부 닫힘 | 그리퍼가 후퇴한 뒤 위 서랍의 관절 위치를 0으로 변경 |
| 재판단 | 닫힘 후 다음 행동 전까지 실제 닫힌 상태임을 로그로 확인 |
| 재열기 요청 | 모델이 `open_drawer`를 다시 호출, 한 번에 동작 완료 |
| 최종 상태 | 약 22.1 cm 개방. 그리퍼를 놓고 후퇴한 안정 상태에서 완료 보고 |

닫힘 직전 개방, 다음 행동 전 닫힘, 행동 후 재개방을 모두 확인했습니다. 실제 API 판단은 4턴, 도구 호출은 2회이며 실패한 호출은 없었습니다. 단일 사례이므로 반복 성공률을 의미하지 않습니다.

120 Hz 물리 스텝마다 최대 속도와 비대상 관절 변위를 집계했습니다. 팔 최대 관절 속도는 약 **0.70002 rad/s**, 두 번째 서랍 최대 이동량은 **7.9×10⁻¹¹ m**, 다른 문 최대 각도는 **2.7×10⁻⁸ rad**로 비대상 움직임은 수치 오차 수준입니다. 두 열기 모두 양쪽 손가락–손잡이 접촉을 확인했고, 최종 그리퍼 개방과 마지막 1.5초 안정화 기준을 통과했습니다. 접촉 중 미세한 속도 변화는 그래프에 남아 있습니다. 이 검사로 모든 충돌의 부재나 실물 로봇 안전성을 보증하지 않습니다.

하위 제어는 **NVIDIA RMPFlow + 이 장면에 보정된 Cartesian 동작 단계**입니다. 관절 목표 변화율을 제한하고 gain을 일정하게 유지하며, 재시도 때 초기 관절 위치로 강제 복귀하지 않습니다. 위 서랍은 `stiffness=0`, `damping=10`의 수동 서랍이며 다른 서랍과 문은 잠그지 않았습니다. 손가락과 손잡이의 물리 접촉으로 서랍을 당깁니다.

카메라는 서랍장 앞의 고정 사선 RGB입니다. 하위 제어는 시뮬레이터의 관절·손잡이 위치를 사용하고, ER 2는 RGB와 도구 종료 상태로 다음 행동을 결정합니다. 닫힘 주입은 외부 개입을 단순화한 관절 위치 변경입니다. 사람의 손으로 미는 접촉은 구현하지 않았습니다.

## 3. Spot 실내 점검 — 차단 후 우회

대표 실행: `outputs/06_patrol/20260922_161220_f0d47862/`

| 단계 | 실제 관찰 |
|---|---|
| 첫 번째 판단 | 모델이 짧은 중앙 경로 `navigate(center)` 선택 |
| 통로 차단 | 보행 중 중앙 경로에 장애물 삽입, 로컬 레이캐스트 제어기가 정지 후 `blocked` 반환 |
| 두 번째 판단 | 같은 Live 세션에서 `navigate(right)` 선택 |
| 우회·도착 | 실제 보행으로 오른쪽 통로 이동. 최종 위치 약 `(3.440, -0.205)` m |
| 세 번째 판단 | 새 전방 영상에서 `red`, `goal_complete` 보고 |
| 평가 | 목표 경유점 `(3.4, 0)`에서 약 20.9 cm 이내, 전도 없음, 색상 일치 |

저수준 이동은 공식 Spot 평지 보행 정책입니다. 자기 위치는 시뮬레이터에서 얻고, 경유점 그래프는 미리 정의했습니다. ER 2는 두 경로 중 다음 행동을 선택하고 표시등을 판독합니다. 빠른 충돌 방지는 로컬 제어기가 처리합니다. 새로운 지도의 SLAM·범용 자율 주행·모델의 연속 관절 제어로 해석하지 않습니다.

입력 카메라는 로봇 위치·진행 방향을 따라가는 전방 RGB 카메라입니다. 실제 Spot의 전체 센서 구성을 재현하지 않았습니다. 단색 사각 표시등과 단순 실내 공간을 사용했습니다.
