1 · 이미지로 ER 2와 일반 Gemini 비교

이미지가 Google API로 전송됩니다. 실행 시 API 사용량이 발생할 수 있습니다. 예측 좌표가 잘못되면 원문과 오류를 그대로 남깁니다.

2 · Isaac Sim 직접 조작

고정 상부 카메라 · 최신 화면

정지 후 재개하려면 장면 초기화. 방해 주입은 명시적으로 물체 위치를 변경하는 조작입니다.

클릭할 고정 관측 이미지

좌표를 선택하세요. 순서는 [y, x]입니다.

카메라 깊이로 3D 위치를 계산하고 실제 그리퍼 접촉으로 집습니다. 장면이 바뀌면 다시 촬영하세요.

실행 결과와 저장 경로가 여기에 표시됩니다.

3 · ER 2에게 로봇 작업 지시

먼저 빨간 블록 1개부터 확인하세요. 여러 개를 옮기려면 지시를 “Put all three blocks into separate empty positions inside the green tray.”로 바꾸고 횟수를 3~6으로 선택합니다. 각 동작 후 새 이미지를 전달합니다.

모델의 실제 함수 호출과 로봇 실행 경로가 표시됩니다.

방해 후 재관찰·복구 실험

장면 1로 초기화해 방해 없는 1회 행동과 방해 있는 최대 3회 판단을 순서대로 실행합니다. 방해 조건에서는 첫 동작 시작 1초(시뮬레이션 시간) 후 빨간 블록을 이동시킵니다. 이후 모델은 새 RGB 이미지로 다음 행동을 선택합니다.

ER 2는 고정 상부 카메라의 이미지 한 장씩을 받습니다. 전체 영상은 기록용입니다. 현재 장면이 초기화되고 API 호출 비용이 발생합니다. 실험 중 추가 방해 버튼은 누르지 마세요.

방해 시점, 단계별 입력·행동, 전체 영상과 복구 판정 경로가 표시됩니다.

Live 스트리밍 · 동작 중 감지·중단·복구

고정 카메라의 JPEG 프레임을 ER 2 Streaming 모델의 지속 WebSocket 세션으로 최대 1 FPS 전송합니다. 첫 행동 중 모델이 목표 이동을 보고하면 동작을 중단하고 Live 세션에서 재계획합니다.

초기 행동은 일반 ER 2가 계획하고 Live 모델이 별도로 감독합니다. 영상만으로 자동 응답하지 않으므로 앞선 판단 완료 후 heartbeat를 전달합니다. 장면 초기화·API 과금이 발생합니다. Live 세션은 240초·최대 24개 판단 턴으로 제한합니다. 저장 후 통합 영상을 만드는 시간이 추가됩니다. 단일 실험 중 다른 버튼은 누르지 않습니다.

완료 후 결과의 presentation/synchronized.mp4를 열면 실제 시뮬레이션·전송 이미지·요청·응답을 한 화면에서 볼 수 있습니다. 각 자료의 타임스탬프로 만든 1배속 동기화 영상입니다.

변화 감지 시각, 동작 중단 여부, 복구 판정과 전송 프레임 경로가 표시됩니다.

5 · 다른 환경: 서랍 조작 / Spot 설비 점검

먼저 터미널에서 해당 환경을 시작합니다. GR_ER2_SCENE=drawer bash scripts/sim.sh start 또는 GR_ER2_SCENE=patrol bash scripts/sim.sh start. 환경 전환 전에는 bash scripts/sim.sh stop을 실행합니다. 현재 화면의 카메라가 새 환경으로 바뀝니다.

실제 ER 2 Live API를 호출하며 비용이 발생합니다. 이 환경에서는 위쪽 블록 전용 조작 버튼을 사용하지 마세요. 결과는 05_drawer / 06_patrol에 저장됩니다.
